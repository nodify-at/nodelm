# License notes

V1 training data permits only these normalized repository licenses:

- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause

Whitespace and well-known display names are normalized before comparison. GPL, AGPL, compound
expressions containing GPL, missing values, and unknown values are not admitted to V1. They
remain in the audit report with the original value, repository, instance ID, disposition, and
reason.

This is a conservative data policy, not legal advice. Dataset-card licensing and a source
repository's code licensing are distinct. A row enters training only after repository-level
evidence is preserved. File-level exceptions, vendored code, license changes over time, and
ambiguous multi-license expressions require manual review.
